# Marketplace San Luis 🏔️🇦🇷 (Supabase Realtime)

Plataforma web colaborativa y moderna para la compra y venta de productos y servicios en la Provincia de San Luis (San Luis Capital, Villa Mercedes, Merlo, Juana Koslay, La Punta, Potrero de los Funes, etc.), integrada con base de datos en tiempo real mediante **Supabase**.

---

## 🚀 Cómo ejecutar el proyecto

Este proyecto está diseñado para funcionar de inmediato sin necesidad de instalar Node.js ni Python:

1. **Apertura Directa**:
   Haz doble clic sobre `index.html` para abrirlo en tu navegador favorito.
2. **Servidor Local (Opcional)**:
   Puedes abrirlo con extensiones como *Live Server* en tu editor de código.

---

## 🗄️ Configuración de Supabase (Paso a Paso)

### 1. Crear Cuenta y Proyecto Gratuito
1. Ingresa a [https://supabase.com](https://supabase.com) y haz clic en **Start your project** (puedes registrarte con tu cuenta de GitHub o correo electrónico).
2. Haz clic en **New project**.
3. Completa los campos:
   - **Name**: `marketplace-san-luis`
   - **Database Password**: Elige una contraseña segura (guárdala).
   - **Region**: Selecciona **South America (São Paulo)** (`sa-east-1`) para la menor latencia desde San Luis / Argentina.
   - **Plan**: Free Plan ($0/mes).
4. Haz clic en **Create new project** y espera ~1 minuto a que se inicialice.

### 2. Crear la Tabla `products` en el SQL Editor
1. En el menú lateral izquierdo de Supabase, haz clic en el ícono de **SQL Editor** (`>_`).
2. Haz clic en **New query**.
3. Pega el siguiente script SQL y presiona el botón **Run**:

```sql
-- 1. Crear tabla de productos con geolocalización y moderación
CREATE TABLE IF NOT EXISTS products (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  title TEXT NOT NULL,
  price NUMERIC NOT NULL,
  category TEXT NOT NULL,
  city TEXT NOT NULL,
  address TEXT,
  lat NUMERIC,
  lng NUMERIC,
  description TEXT,
  seller TEXT NOT NULL,
  phone TEXT NOT NULL,
  image TEXT,
  featured BOOLEAN DEFAULT FALSE,
  estado TEXT DEFAULT 'aprobado'
);

-- Si la tabla ya fue creada anteriormente, agregar columnas necesarias:
ALTER TABLE products ADD COLUMN IF NOT EXISTS estado TEXT DEFAULT 'aprobado';
ALTER TABLE products ADD COLUMN IF NOT EXISTS address TEXT;
ALTER TABLE products ADD COLUMN IF NOT EXISTS lat NUMERIC;
ALTER TABLE products ADD COLUMN IF NOT EXISTS lng NUMERIC;
UPDATE products SET estado = 'aprobado' WHERE estado IS NULL;

-- 2. Habilitar seguridad por fila (Row Level Security)
ALTER TABLE products ENABLE ROW LEVEL SECURITY;

-- 3. Crear políticas para lectura y publicación pública
CREATE POLICY "Lectura publica de avisos" 
ON products FOR SELECT 
USING (true);

CREATE POLICY "Publicacion publica de avisos" 
ON products FOR INSERT 
WITH CHECK (true);

-- 4. Activar sincronización en tiempo real (Realtime)
ALTER PUBLICATION supabase_realtime ADD TABLE products;
```

### 3. Obtener la URL y la API Key
1. En el menú lateral izquierdo de Supabase, ve a **Project Settings** (el engranaje ⚙️) -> **API**.
2. Copia los siguientes dos valores:
   - **Project URL**: Ejemplo: `https://abcdefghijklm.supabase.co`
   - **Project API Keys -> `anon` / `public`**: Un token largo que empieza con `eyJhbGciOi...`

### 4. Conectar al Marketplace
Tienes dos opciones sencillas:
- **Desde la Web**: Abre `index.html`, haz clic en el botón **"Conectar Supabase"** en la barra superior o en el banner superior, pega tu URL y tu Key Anónima, y presiona **Guardar y Conectar**.
- **O editando el código**: Abre `app.js` y coloca tus credenciales en `HARDCODED_SUPABASE_URL` y `HARDCODED_SUPABASE_KEY`.

## 🗺️ Configuración de Google Maps Platform (Maps Demo Key)

El proyecto cuenta con integración completa de **Google Maps Platform** utilizando la **Maps Demo Key** oficial (para prototipar de inmediato sin ingresar tarjeta de crédito):

### 1. Obtener la Maps Demo Key (Sin Tarjeta)
1. Ingresa a [https://mapsplatform.google.com/maps-demo-key](https://mapsplatform.google.com/maps-demo-key?utm_campaign=gmp_git_agentskills_v1).
2. Inicia sesión con cualquier cuenta de Google.
3. Acepta los términos del *Maps Demo Project*.
4. Haz clic en generar para obtener tu clave (comienza con `AIzaSy...`).

### 2. Activar en el Marketplace
- Abre `index.html`, haz clic en el botón **"Google Maps"** en la barra superior.
- Pega tu Demo Key y presiona **Guardar y Activar**.

### 3. Funcionalidades de Google Maps Habilitadas:
- **Maps JavaScript API (Vector Map)**: Vista 2D/3D con Street View y control de satélite para San Luis y Villa Mercedes.
- **AdvancedMarkerElement**: Marcadores interactivos categorizados por rubros comerciales con ventanas de información (InfoWindow) conectadas a WhatsApp.
- **Places UI Kit / PlaceAutocompleteElement**: En el formulario de publicación, las direcciones de Villa Mercedes, San Luis Capital y alrededores se sugieren automáticamente al tipear.
- **Geocodificación Automática**: Al seleccionar una dirección en el autocompletado, se calculan automáticamente la latitud y longitud exactas, y se seleccionan la localidad correspondiente para guardarse de forma directa en Supabase.

## ✨ Características en Tiempo Real

1. **Lectura directa desde PostgreSQL**: Las publicaciones provienen de la base de datos en la nube.
2. **Sincronización Realtime (`postgres_changes`)**: Si una persona publica un aviso desde otra pestaña, computadora o teléfono, aparece automáticamente en pantalla sin recargar la página.
3. **Persistencia Dinámica**: Cada nuevo aviso ingresado en el formulario se guarda de forma persistente en Supabase.
4. **Respaldo Inteligente**: Si aún no configuraste Supabase o estás sin conexión, el sistema utiliza un catálogo local de respaldo para que la web siga siendo 100% interactiva.
